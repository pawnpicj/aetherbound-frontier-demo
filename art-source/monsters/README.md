# Sanctuary monsters v6

Original enemy artwork generated with the built-in Imagegen tool. Bramble Imp appears three times; Rift Wisp appears twice. Each source PNG has six transparent illustrated poses: idle, preparation, attack, charged attack, hit, defeated. Phaser sequences these key poses with tweens and effects.

Sources: `bramble-v6.png`, `wisp-v6.png`. Runtime: `public/assets/monsters/<bramble|wisp>/atlas-v6.webp` and `pose-0-v6.webp` through `pose-5-v6.webp`. `scripts/prepare-monsters.mjs` verifies RGBA transparency and packs the six frames. The original generator output remains intact.
