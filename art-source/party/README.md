# Complete roster artwork v3

Five original character pose atlases created with the built-in Imagegen tool. Kael's existing art is the style reference; each new character has its own generation call, costume, silhouette, weapon and six illustrated key poses. The runtime sequences these poses with Phaser tweens and elemental effects. These are pose-based animation prototypes, not full frame-by-frame animation sets.

Final source assets: `lyra-v3.png`, `orin-v3.png`, `ren-v3.png`, `mira-v3.png`, `hollowguard-v3.png` in this directory. Runtime assets: `public/assets/characters/<id>/atlas-v3.webp`, `portrait-v3.webp` and `pose-0-v3.webp` through `pose-5-v3.webp`. Original source files remain intact. The packing pipeline preserves transparency and selects each pose's alpha components to exclude neighboring drawings that touch a cell divider, while retaining substantial detached props such as Mira's book.
